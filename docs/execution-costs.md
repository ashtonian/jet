# Value, output and builtin costs

`Template.ExecuteContext` shares value/output reservations with its context, work and depth state. Positive limits apply throughout nested execution. The compatibility `Execute` API retains its original default functions and extension points.

`MaxValueBytes` counts cumulative logical construction. A string destination consumes its payload size; a collection consumes newly constructed slots. Reservations use checked arithmetic before allocation, conversion or buffer growth. Proven upper bounds may reserve more than the eventual result. Charges are retained after rollback or discard. Failed reservations, negative requests and unrepresentable construction sizes terminate with `ErrValueLimit`; output exhaustion terminates with `ErrOutputLimit`. Both preserve `errors.Is` and `LimitError` inspection.

This allowance counts produced payload rather than Go heap/RSS. It excludes caller-owned input, compiled source/AST storage, allocator capacity, pool misses and fixed-size interpreter/printing workspaces. Initial input and compilation need their own admission limits. Native code and unsupported reflection have separate capability boundaries.

## Construction schedule

Widths below use the current architecture's Go storage widths. Container children are aliases unless a conversion/copy creates another destination; their historical allocations are not recursively charged again.

| Operation | Reservation / work |
| --- | --- |
| String/byte concatenation | Destination payload before construction; primitive formatting uses bounded scratch. Composite data-only formatting reserves incrementally. |
| Byte/rune/string conversion | Exact byte-copy length or a proven rune-encoding bound before reflection. Invalid conversions return ordinary template errors. |
| Reflection argument list | Newly constructed `reflect.Value` slots. |
| Scope insertion | New string-key and `reflect.Value` slots; key payload can alias source. |
| `map` | Requested string-key/interface-value slots, plus allocating key conversions. Metered keys are evaluated once and the validated/converted value is inserted. |
| `slice`, `array`, `split` | New interface/string-header slots. Split segments alias source bytes. |
| `repeat`, `replace` | Checked destination size before the native operation. Replace counts actual matches, including UTF-8 boundaries for empty patterns. |
| `lower`, `upper`, `html`, `url` | Size/bound before construction; unchanged aliases avoid a payload reservation. |
| Numeric string parsing | Twice the input length is reserved for possible native error copies. Error text omits the input while retaining `*strconv.NumError` through `errors.As`. |
| Data-only printing | Primitive/collection traversal consumes work/depth; map sorting reserves key slots. Strings stream through bounded scratch. |
| Data-only JSON | Bounded incremental result buffer; sorted map-key slots; string marshaling reserves two proven encoding bounds before the native scalar encoder. Float marshaling reserves a fixed 128-byte bound. Byte-slice base64 streams into the charging buffer. |
| Try output | Retained bytes before buffer growth, and another retained copy when committed into a parent try. |
| `ints` | Fixed-size ranger construction plus work per advance. Metered ranges exceeding int64 index capacity are ordinary argument errors; endpoint advancement avoids wrap. |

Data-dependent operations consume work proportional to scanned/generated bytes and visited items. Sizing/counting passes also consume work. Prepaid standard-library operations check cancellation before/after their bounded call; their uninterrupted work depends on admitted input and remaining work allowance. Step totals and conservative reservation bounds are implementation details rather than billing units.

## Generated output and transactions

Output is charged after escaping. The allowance includes raw output, JSON, SafeWriter/Renderer writes, failed try bodies and output discarded by `exec`. It measures generation rather than only successful caller-sink bytes.

A try commit transfers already charged output without another output charge. Copying into a parent buffer still reserves newly retained value bytes and work. Rollback refunds neither allowance. Cancellation, resource failures and latched writer errors bypass template catch/isset recovery.

An over-limit write rejects its entire chunk before the next sink. Earlier committed bytes may remain. A sink's partial count/error is preserved at the checked boundary; a nil-error short write becomes `io.ErrShortWrite`. A checked latch prevents ignored SafeWriter/Renderer errors, or recovery of the control-flow panic, from turning failure into success. `SafeWriter` keeps its public signature.

Callers needing atomic publication should render into their owned buffer, discard it on error and publish only after success. An arbitrary blocked writer remains native code; the interpreter waits for it to return.

## Builtin and native boundaries

Metered defaults are private immutable bindings with their implementation and disposition. Aliases and pipeline calls retain the binding. Function names and program counters grant no authority. The supported default operations are:

- String operations: lower, upper, hasPrefix, hasSuffix, repeat, replace, split, trimSpace, html and url.
- Output operations: safeHtml, safeJs, raw, unsafe, json and writeJson, using the supported data-only formatting/serialization paths.
- Interpreter operations: map, slice, array, len, isset, ints, includeIfExists and exec.

`dump` retains unrestricted diagnostic behavior and has an explicit diagnostic-only disposition for restricted policy to deny. Arbitrary Formatter/Stringer/Error/Marshaler hooks, external Renderer/Ranger/SafeWriter implementations, channels, native JSON types/structs/non-string-key maps and other unsupported reflection remain unrestricted host capabilities. Native fallbacks pass the runtime's invocation checkpoint; a restricted policy must deny unsupported capabilities before invocation. This API alone does not enable that policy.

Registered globals/functions can shadow defaults. Such registration remains a host callback and does not acquire audited status from the name. Runtime Resolve/MustResolve and direct native arguments expose original function values for unrestricted interoperability; function-valued containers are outside the data-only restricted profile. Calling an extracted native function is outside interpreter-owned metering.

Metered diagnostics identify positions, identifiers and types without expanding runtime scopes or arbitrary values. Legacy Execute retains its diagnostic behavior. Actual native programming panics preserve the runtime's documented panic contract.

## Cooperative adapters

Owned `jet.Func`/Renderer adapters may call:

```go
r.ConsumeSteps(work)        // uint64, before the corresponding work
r.ReserveValueBytes(bytes) // int64, before construction
```

Both use the active execution and sticky termination path. Checked size arithmetic, width/precision validation and every separately allocated destination are the adapter's responsibility. Reserving after a native function returns cannot prevent its allocation. These hooks do not approve a callback for restricted execution or preempt it. Runtime/Arguments values belong to the current synchronous invocation and must not be retained for later work.

Normal and race compatibility checks remain separate. Allocation/control regressions use fixed finite inputs; neither logical quotas nor a Go heap target provide process isolation.
