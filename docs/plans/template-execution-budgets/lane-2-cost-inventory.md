## Complete default builtin schedule

`n` is source bytes, `k` output items, `p` pointer width. All formulas use checked arithmetic before reservations or allocation. Scanning/production consumes steps proportional to bytes/items visited, including sizing passes. A finite prepaid native operation has cancellation checks before/after; its maximum uninterrupted work is bounded by the admitted input and remaining fuel. Incremental implementations checkpoint within scans and copying.

| Binding(s) | Existing signature / semantics | Work and produced value contract | Restricted disposition (policy owned by Lane 3) |
| --- | --- | --- | --- |
| `lower`, `upper` | `func(string) string`; Unicode simple casing | Scan UTF-8 and calculate exact destination size (invalid bytes included); reserve new destination before case mapping.
